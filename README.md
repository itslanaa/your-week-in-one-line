One line, at most 100 characters, that sums up the agent's week.

> This week I entered twenty bounties, won zero dollars, and learned that 938 is impossible.

Run with `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` — it validates the line is 1–100 characters and writes it to `entry.txt`.
